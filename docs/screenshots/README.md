# Screenshot Guide

1. Run the app locally:

   ```bash
   npm run dev
   ```

2. Open the app in a browser.
3. Load sample ingredients for each station.
4. Capture screenshots:
   - `home.png`
   - `seqsieve.png`
   - `readlens.png`
   - `seqcompare.png`
   - `orfscout.png`
   - `hmmforge.png`
   - `workflow.png`
5. Save them in `docs/screenshots/`.

Optional future improvement: add `npm run screenshots` with Playwright. Playwright is not required for the current app.
