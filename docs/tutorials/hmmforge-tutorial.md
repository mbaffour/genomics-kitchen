# Using HMMForge to prepare protein families for HMM workflows

HMMForge prepares protein FASTA files for external alignment and profile HMM workflows. It does not run MAFFT or HMMER in the browser.

Use exact deduplication, length filters, ambiguity filters, terminal-stop trimming, safe alignment IDs, and outlier flagging. Review kept, flagged, removed, duplicate, and mapping tables before building an HMM.

Export cleaned FASTA, removed FASTA, flagged FASTA, safe ID mapping TSV, duplicate mapping TSV, sequence QC TSV, workflow commands, report, and JSON.
