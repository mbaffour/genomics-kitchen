# Comparing multiple FASTA files with SeqCompare

Workflow: upload multiple files -> normalize -> compare -> export core/accessory/specific sets.

1. Upload two or more FASTA files.
2. Compare by exact sequence content when IDs may differ across pipelines.
3. Review core, accessory, file-specific, subset, pairwise, and matrix results.
4. Export core FASTA, accessory FASTA, file-specific FASTA, presence/absence TSV, pairwise TSV, report, and JSON.
