# Using ORFScout to find ORFs and translate sequences

ORFScout scans nucleotide FASTA records for candidate open reading frames and six-frame translations. ORF prediction is not gene annotation.

Choose genetic code, start codons, stop codons, minimum ORF length, search mode, partial-ORF handling, and strand. Coordinates are reported as 1-based inclusive positions and reverse-strand ORFs are mapped back to original sequence coordinates.

Export ORF nucleotide FASTA, ORF protein FASTA, ORF table TSV, six-frame translation FASTA, report, and JSON.
